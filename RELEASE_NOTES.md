# Focus Veil 0.1.0

Focus Veil is a private, native macOS menu-bar utility that keeps the focused window clear while softly blurring and dimming the background.

## Highlights

- Smooth, rounded focus cutout with an elevated edge and shadow
- Soft Frost, Balanced, and Deep Focus background treatments
- Continuous intensity control
- Deliberate pointer-shake toggle
- Mission Control support
- Local-only operation with no analytics, network access, or Screen Recording permission

## Install

1. Download `Focus-Veil-0.1.0.dmg`.
2. Open it and drag **Focus Veil** into **Applications**.
3. Launch Focus Veil and grant Accessibility access when macOS asks.

Requires macOS 14 or later. The universal build runs natively on Apple Silicon and Intel Macs.
